# 🌟 Portfólio

Oi, bem-vindo(a) ao meu cantinho. Este projeto é meu portfólio pessoal, onde compartilho um pouco sobre minha jornada como desenvolvedor de software, meus projetos e minhas paixões.

Desenvolvido com React, TypeScript, Vite e Tailwind CSS, este site reflete minhas habilidades técnicas e também um pouco da minha personalidade. A ideia é manter uma experiência minimalista, clara e profissional, sem perder o toque pessoal.

Quando não estou codando, você provavelmente vai me encontrar explorando o universo geek, acompanhando alguma obra que me prende de verdade ou mergulhando em uma nova tecnologia. Essa curiosidade faz parte de quem eu sou e aparece na forma como estudo, resolvo problemas e crio soluções.

## 🚀 Executando o projeto

### 📋 Pré-requisitos

- Node.js instalado.
- npm instalado.

### 💻 Instalação

Instale as dependências:

```bash
npm install
```

### 📜 Scripts disponíveis

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Compile para produção:

```bash
npm run build
```

Execute a validação de lint:

```bash
npm run lint
```

Visualize a build de produção localmente:

```bash
npm run preview
```
